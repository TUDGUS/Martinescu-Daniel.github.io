# Clever Cubed [Digital / Fan / Companion] Game

A implementation of the roll-and-write dice game **Clever Cubed** (originally designed by Wolfgang Warsch and published by Schmidt Spiele).

The version implemented, features a solo mode as well as the ability to play with 3 other players and a functioning AI with different tactics available at its disposal

## 🎮 Features

- [ ] Full implementation of all five scoring zones (Yellow, Turquoise, Blue/Purple, Brown, Pink)
- [ ] [Dice rolling and silver platter mechanics]
- [ ] [Score tracking and end-game summary]


To play it, simply download the content files, and then compile and run the program on your device
